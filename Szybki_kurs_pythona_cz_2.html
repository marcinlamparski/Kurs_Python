Lekcja 00

Tekst, czyli str

Tekst w Pythonie ma typ str (z angielskiego string, czyli ciąg znaków). Znakiem jest litera, cyfra, spacja albo znak interpunkcyjny. Tekst zapisujesz w cudzysłowie " " albo w apostrofach ' ' — ważne, żeby zamknąć go tym samym znakiem, którym go otworzyłeś.

imie = "Ola"
miasto = 'Rybnik'
print(imie, miasto)
Ola Rybnik

Gdy w tekście chcesz użyć apostrofu, otocz go cudzysłowami (i odwrotnie):

print("To jest 'cytat' w tekście")
print('A to jest "cudzysłów" w apostrofach')
To jest 'cytat' w tekście
A to jest "cudzysłów" w apostrofach

Znaki specjalne

Ukośnik \ w tekście zaczyna zapis znaku specjalnego:

ZapisZnaczenie
\nprzejście do nowej linii
\ttabulator (większy odstęp)
\"cudzysłów wewnątrz tekstu w cudzysłowie
\\sam ukośnik
print("Pierwsza linia\nDruga linia")
print("Imię:\tOla")
print("Powiedziała: \"Cześć!\"")

Druga linia
Imię:	Ola
Powiedziała: "Cześć!"
Pusty tekst "" nie ma żadnych znaków. Przyda się jako punkt startowy, gdy będziesz budować wynik litera po literze. Uwaga: cyfry w cudzysłowie to nadal tekst — "5" nie jest liczbą 5.

Łączenie, powielanie i f-stringi

Na tekstach działają dwa znane Ci operatory, ale znaczą coś innego niż przy liczbach.

Łączenie: +

Plus skleja teksty w jeden (to konkatenacja). Nie dodaje spacji — musisz je wstawić sam.

imie = "Ala"
nazwisko = "Kowalska"
print(imie + nazwisko)
print(imie + " " + nazwisko)
AlaKowalska
Ala Kowalska

Powielanie: *

Mnożenie tekstu przez liczbę całkowitą powtarza go tyle razy.

print("ha" * 3)
print("-" * 20)
hahaha

Tekst i liczba

Nie możesz skleić tekstu z liczbą. Zamień liczbę na tekst funkcją str().

wiek = 17
print("Mam " + wiek + " lat")
TypeError: can only concatenate str (not "int") to str
wiek = 17
print("Mam " + str(wiek) + " lat")
Mam 17 lat

f-string, czyli wygodne wstawianie wartości

Wpisz literę f przed cudzysłowem, a zmienne i wyrażenia umieszczaj w klamrach { }. Python sam wstawi ich wartości i zamieni je na tekst.

imie = "Ola"
wiek = 17
print(f"Cześć, {imie}! Masz {wiek} lat.")
print(f"Za rok będziesz mieć {wiek + 1} lat.")
Cześć, Ola! Masz 17 lat.
Za rok będziesz mieć 18 lat.
Pamiętaj: input() zawsze zwraca tekst. Dlatego "5" + "5" daje "55", a nie 10. Liczby z input() zamieniaj na int(), jak w części pierwszej.

Lekcja 03

Wycinki tekstu

Wycinek (po angielsku slice) to fragment tekstu. Zapisujesz go jako tekst[od:do]. Znak o indeksie od wchodzi do wycinka, a znak o indeksie do już nie (tak samo jak górna granica w range()).

tekst = "programowanie"
print(tekst[0:7])
print(tekst[:7])
print(tekst[7:])
print(tekst[-5:])
program
program
owanie
wanie
  • pominięty początek ([:7]) oznacza „od początku”,
  • pominięty koniec ([7:]) oznacza „do końca”,
  • ujemne indeksy liczą od końca, więc [-5:] to ostatnie pięć znaków.

Krok i odwracanie

Trzecia liczba to krok: tekst[od:do:krok]. Krok -1 idzie od tyłu, więc [::-1] odwraca cały tekst.

tekst = "programowanie"
print(tekst[::2])
print(tekst[::-1])
pormwne
einawomargorp

Jak „zmienić” literę

Skoro tekst jest niezmienny, sklejasz nowy z kawałków starego:

slowo = "Python"
nowe = "J" + slowo[1:]
print(nowe)
Jython

Lekcja 09

Mini-projekty: palindrom, samogłoski i szyfr

Czas połączyć wszystko, czego się nauczyłeś. To klasyczne zadania na tekstach, które pojawiają się też na lekcjach algorytmiki.

1. Palindrom

Palindrom czyta się tak samo od przodu i od tyłu, np. kajak. Zdanie przed sprawdzeniem zamieniamy na małe litery i usuwamy spacje.

def czy_palindrom(tekst):
    tekst = tekst.lower().replace(" ", "")
    return tekst == tekst[::-1]

print(czy_palindrom("Kajak"))
print(czy_palindrom("Kobyła ma mały bok"))
print(czy_palindrom("Python"))
True
True
False

3. Szyfr Cezara

Szyfr Cezara przesuwa każdą literę o stałą liczbę miejsc w alfabecie (klucz). Przy kluczu 3: a→d, b→e, a z→c, bo po z wracamy na początek alfabetu. Dla jednej litery robimy trzy kroki:

  1. ord(znak) - ord("a") — numer litery w alfabecie (a = 0, b = 1…),
  2. (numer + klucz) % 26 — przesunięcie z zawinięciem na początek (alfabet ma 26 liter),
  3. chr(ord("a") + nowy_numer) — powrót do litery.

Znaki spoza a–z (spacje, cyfry, polskie litery) zostawiamy bez zmian.

def szyfruj(tekst, klucz):
    wynik = ""
    for znak in tekst:
        if znak >= "a" and znak <= "z":
            numer = (ord(znak) - ord("a") + klucz) % 26

Wyzwanie: wielkie litery w szyfrze

Rozbuduj funkcję szyfruj tak, aby szyfrowała także wielkie litery A–Z (wielkie nadal mają pozostać wielkie).

Pokaż rozwiązanie
def szyfruj(tekst, klucz):
    wynik = ""
    for znak in tekst:
        if znak >= "a" and znak <= "z":
            numer = (ord(znak) - ord("a") + klucz) % 26
            wynik = wynik + chr(ord("a") + numer)
        elif znak >= "A" and znak <= "Z":
            numer = (ord(znak) - ord("A") + klucz) % 26
            wynik = wynik + chr(ord("A") + numer)
        else:
            wynik = wynik + znak
    return wynik

def czy_anagram(a, b):
    return sorted(a.lower()) == sorted(b.lower())
