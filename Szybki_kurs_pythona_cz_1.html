kurs podstaw — klasa II liceum

Naucz komputer rozumieć Twoje polecenia.

Python to jeden z najprostszych języków programowania do rozpoczęcia nauki. W tym kursie, krok po kroku, napiszesz swoje pierwsze programy — bez wcześniejszego doświadczenia.

Zaczynamy ↓
>>> print("Witaj, świecie!")

Lekcja 00

Zanim zaczniesz

Python to język programowania — sposób zapisywania poleceń, które wykonuje komputer. Programy piszesz w zwykłym pliku tekstowym z rozszerzeniem .py, a interpreter Pythona czyta go linijka po linijce i wykonuje.

Do pisania kodu potrzebujesz edytora. Na start dobrze sprawdzą się:

  • Thonny — darmowy program do zainstalowania, idealny dla początkujących.
  • pickcode.io — działa w przeglądarce, nic nie trzeba instalować.
Ważne: Python jest wrażliwy na wielkość liter i wcięcia (spacje na początku linii). Zobaczysz, dlaczego to istotne, przy instrukcjach warunkowych i pętlach.
Lekcja 01

print() — wypisywanie na ekran

Funkcja print() wyświetla tekst lub wartość w oknie programu. To pierwsze polecenie, które napisze niemal każdy programista.

print("Witaj, świecie!")
print("Python", "jest", "proste")
print(2 + 2)

Tekst (napis) zawsze zapisujesz w cudzysłowach " " lub apostrofach ' '. Liczby zapisujesz bez nich.

Ćwiczenie: co wypisze ten kod?

Zastanów się, co wypisze program, zanim sprawdzisz odpowiedź.

print("5 + 5")
print(5 + 5)
Pokaż rozwiązanie

Pierwsza linia wypisze dosłowny tekst 5 + 5 (bo to napis w cudzysłowie). Druga wykona działanie i wypisze 10.

Lekcja 02

input() — pobieranie danych od użytkownika

Funkcja input() zatrzymuje program i czeka, aż użytkownik coś wpisze i naciśnie Enter. To, co wpisze, program zapamiętuje jako tekst.

imie = input("Jak masz na imię? ")
print("Cześć,", imie)
Uwaga: input() zawsze zwraca tekst (nawet gdy użytkownik wpisze liczbę). Jeśli chcesz na tej liczbie liczyć, musisz ją zamienić — o tym za chwilę, w lekcji o zmiennych.
Ćwiczenie: napraw błąd

Ten kod ma zwrócić sumę dwóch liczb podanych przez użytkownika, ale zamiast liczyć — skleja teksty (np. dla 2 i 3 wypisze 23 zamiast 5):

a = input("Podaj liczbę: ")
b = input("Podaj drugą: ")
print(a + b)
Pokaż rozwiązanie

Rozwiązanie: zamień wpisany tekst na liczbę funkcją int(): a = int(input("Podaj liczbę: ")).

Lekcja 03

Zmienne i typy danych

Zmienna to nazwane miejsce w pamięci komputera, w którym przechowujesz wartość. Nadajesz jej nazwę i przypisujesz wartość znakiem =.

wiek = 17
srednia = 4.5
szkola = "Technikum TEB"
czy_zdal = True

Podstawowe typy danych, z którymi spotkasz się na start:

  • int — liczba całkowita, np. 17
  • float — liczba zmiennoprzecinkowa (z częścią dziesiętną), np. 4.5
  • str — tekst (string), np. "cześć"
  • bool — wartość logiczna, True lub False
  • list — lista wielu wartości w nawiasach kwadratowych, np. [3, 5, 8] (poznasz ją w lekcji 07)

Typ zmiennej sprawdzisz funkcją type(), a między typami przekonwertujesz funkcjami int(), float(), str().

tekst = "20"
liczba = int(tekst)
print(liczba + 5)  # 25
Nazwy zmiennych zaczynają się od litery lub podkreślnika, nie zawierają spacji i (zgodnie z konwencją) są pisane małymi literami, np. liczba_uczniow.
Ćwiczenie: jaki to typ?

Jaki typ danych będą miały poniższe zmienne: x = 10, y = "10", z = 10.0, w = False?

Pokaż rozwiązanie

Odpowiedź: x → int, y → str, z → float, w → bool.

Lekcja 04

Operatory i działania matematyczne

Operatory arytmetyczne

10 + 3   # dodawanie → 13
10 - 3   # odejmowanie → 7
10 * 3   # mnożenie → 30
10 / 3   # dzielenie → 3.333...
10 // 3  # dzielenie całkowite → 3
10 % 3   # reszta z dzielenia → 1
10 ** 2  # potęgowanie → 100

Operatory porównania

Zwracają True albo False: == (równe), != (różne), >, <, >=, <=.

Operatory logiczne

and (i), or (lub), not (zaprzeczenie) — łączą warunki, np. wiek >= 13 and wiek <= 19.

Ćwiczenie: policz wynik

Ile wyniesie 17 % 5?

Pokaż rozwiązanie

Odpowiedź: 2 — 17 podzielone przez 5 daje 3 reszty 2, a operator % zwraca właśnie tę resztę.

Lekcja 05

Instrukcje warunkowe

Instrukcja if pozwala programowi podjąć decyzję — wykonać inny kod w zależności od spełnienia warunku.

wiek = int(input("Podaj swój wiek: "))

if wiek >= 18:
    print("Jesteś pełnoletni.")
elif wiek >= 13:
    print("Jesteś nastolatkiem.")
else:
    print("Jesteś dzieckiem.")
Wcięcia mają znaczenie. Kod należący do if, elif lub else musi być wcięty (zwykle 4 spacje). To właśnie wcięcie mówi Pythonowi, co należy do danego warunku.
Ćwiczenie: dopisz warunek

Napisz warunek, który sprawdzi, czy liczba n jest parzysta. Podpowiedź: liczba jest parzysta, gdy reszta z dzielenia przez 2 wynosi 0.

Pokaż rozwiązanie

Rozwiązanie: if n % 2 == 0: print("parzysta")

Lekcja 06

Pętle

Pętle powtarzają fragment kodu wiele razy — bez pętli musiałbyś przepisywać tę samą instrukcję ręcznie.

Pętla for

Powtarza kod dla każdego elementu zakresu lub kolekcji. Najczęściej używasz jej z funkcją range().

for i in range(1, 6):
    print(i, "razy 3 to", i * 3)

range(1, 6) generuje liczby od 1 do 5 (bez 6) — górna granica jest zawsze wyłączona.

Pętla while

Powtarza kod, dopóki warunek jest prawdziwy. Używasz jej, gdy nie znasz z góry liczby powtórzeń.

licznik = 0
while licznik < 3:
    print("Powtórzenie numer", licznik)
    licznik = licznik + 1
Jeśli zapomnisz zwiększyć licznik w pętli while, warunek nigdy się nie zmieni — program utknie w nieskończonej pętli.
Ćwiczenie: tabliczka mnożenia

Jak pętlą for wypisać tabliczkę mnożenia liczby 5 (od 1 do 10)?

Pokaż rozwiązanie

Rozwiązanie: for i in range(1, 11): print(5 * i)

Lekcja 07

Listy

Zmienna zwykle przechowuje jedną wartość. Gdy masz ich wiele (oceny, imiona, wyniki), używasz listy: jednej zmiennej, która trzyma wiele wartości po kolei. Zapisujesz ją w nawiasach kwadratowych, a elementy rozdzielasz przecinkami. To, co w innych językach nazywa się tablicą, w Pythonie jest właśnie listą.

oceny = [5, 4, 3, 5, 2]
imiona = ["Ola", "Kuba", "Ewa"]
pusta = []

print(oceny)
print(type(oceny))  # <class 'list'>

Dostęp do elementów

Elementy numerujesz od 0. Numer, czyli indeks, wpisujesz w nawiasach kwadratowych za nazwą listy. Indeks ujemny liczy od końca: -1 to ostatni element.

imiona = ["Ola", "Kuba", "Ewa"]
print(imiona[0])   # Ola
print(imiona[2])   # Ewa
print(imiona[-1])  # Ewa

imiona[1] = "Marek"   # zmiana elementu
print(imiona)         # ['Ola', 'Marek', 'Ewa']

Długość listy: len()

Funkcja len() zwraca liczbę elementów listy. Ostatni indeks to zawsze len(lista) - 1. Odwołanie do indeksu spoza listy kończy program błędem IndexError.

imiona = ["Ola", "Marek", "Ewa"]
print(len(imiona))      # 3
print(len([]))          # 0
print(imiona[len(imiona) - 1])  # Ewa

Dodawanie i usuwanie

append(x) dodaje element na koniec listy, a remove(x) usuwa pierwszy element o podanej wartości.

zakupy = ["chleb", "mleko"]
zakupy.append("ser")
print(zakupy)         # ['chleb', 'mleko', 'ser']

zakupy.remove("mleko")
print(zakupy)         # ['chleb', 'ser']
print(len(zakupy))    # 2

Czy element jest na liście?

Operator in sprawdza, czy wartość występuje na liście, i zwraca True albo False.

zakupy = ["chleb", "ser"]
print("ser" in zakupy)    # True
print("masło" in zakupy)  # False

Lista i pętla for

Pętla for potrafi przejść po wszystkich elementach listy. W każdym obiegu zmienna pętli to kolejny element.

oceny = [5, 4, 3, 5, 2]
suma = 0
for ocena in oceny:
    suma = suma + ocena

print("Suma:", suma)                  # Suma: 19
print("Średnia:", suma / len(oceny))  # Średnia: 3.8

Gdy potrzebujesz też numeru elementu, przejdź po indeksach za pomocą range(len(lista)):

imiona = ["Ola", "Marek", "Ewa"]
for i in range(len(imiona)):
    print(i, imiona[i])
# 0 Ola
# 1 Marek
# 2 Ewa
Na skróty: sum(lista) zwraca sumę liczb, max(lista) największą, a min(lista) najmniejszą wartość. Np. max([5, 4, 3]) daje 5.
Ćwiczenie 1: temperatury

Dana jest lista temperatury = [12, 15, 9, 18, 14]. Wypisz, ile ma elementów, jaka jest największa temperatura i ile wynosi średnia.

Pokaż rozwiązanie
temperatury = [12, 15, 9, 18, 14]
print("Liczba pomiarów:", len(temperatury))             # 5
print("Największa:", max(temperatury))                  # 18
print("Średnia:", sum(temperatury) / len(temperatury))  # 13.6
Ćwiczenie 2: lista imion

Program ma trzy razy zapytać o imię, zapisać je na liście, a na końcu wypisać liczbę imion i całą listę. Użyj pętli for i metody append().

Pokaż rozwiązanie
imiona = []
for i in range(3):
    imie = input("Podaj imię: ")
    imiona.append(imie)

print("Wpisano", len(imiona), "imion:", imiona)
Lekcja 08

Funkcje

Funkcja to nazwany fragment kodu, który możesz wywołać wielokrotnie, zamiast powtarzać go za każdym razem. Definiujesz ją słowem def.

def powitaj(imie):
    print("Cześć,", imie + "!")

powitaj("Ola")
powitaj("Kuba")

Funkcja może też zwracać wynik słowem return, żebyś mógł go zapisać w zmiennej lub wykorzystać dalej:

def dodaj(a, b):
    return a + b

wynik = dodaj(4, 7)
print(wynik)  # 11

imie, a i b to parametry — wartości, które funkcja przyjmuje przy wywołaniu.

Ćwiczenie: napisz funkcję

Napisz funkcję czy_parzysta(n), która zwraca True, jeśli liczba jest parzysta.

Pokaż rozwiązanie

Rozwiązanie: def czy_parzysta(n): return n % 2 == 0
